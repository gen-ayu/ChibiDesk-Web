# ChibiDesk — Product Information & Brand Context

## 1. What is ChibiDesk?

**ChibiDesk** is a dedicated Windows desktop customization application designed to make desktop personalization simple, fast, visual, and accessible to everyone.

The core philosophy behind ChibiDesk is allowing users to bring animated and visual elements directly onto their Windows desktop without dealing with complex configurations, high resource overhead, or fragmented third-party tools. It is built as a focused desktop overlay manager rather than a complex media editor.

### Key Pillars
* **Desktop Customization**: Seamlessly integrate dynamic overlays and visual assets into the Windows workspace.
* **Animated & Visual Focus**: Purpose-built support for high-framerate animated media and crisp static imagery.
* **Streamlined Asset Management**: Import, organize, and preview local media in a central, easy-to-use library.
* **Effortless Desktop Placement**: One-click placement, simple repositioning, resizing, and persistent state restoration across reboots.
* **Lightweight & High Performance**: Built to run quietly in the background with minimal CPU/RAM impact.
* **Polished User Experience**: Approachable for beginners while retaining the precision and stability expected by power users.

## 2. Product Vision

The long-term vision for ChibiDesk is to become the **all-in-one destination for desktop customization**—bringing animated and visual desktop elements together in one unified, lightweight application.

ChibiDesk is not merely another media viewer or wallpaper utility. It is designed to establish a cohesive platform where users can personalize their screen space using diverse visual content types through an intuitive, fluid interface.

### The Public Messaging Boundary
> **"More is coming. Stay tuned."**

* **Curiosity over Overexposure**: The website and public channels should tease the broader vision and generate anticipation without publishing unannounced features, specific future version plans (e.g., avoiding statements like *"Version 2 will have X"* or *"We're adding Y next"*), or internal milestones.
* **Focused Present, Open Horizon**: Celebrate what is available and functional today while signaling that the platform is actively evolving.

## 10. Supported Formats & Core Application Concepts

### Confirmed / Active Media Formats
* **GIF** (Animated Graphics Interchange Format)
* **APNG** (Animated Portable Network Graphics)
* **MP4** (H.264 / MPEG-4 Video)
* **WebM** (Lightweight Web Video)
* **Static Visual Assets** (PNG, JPG/JPEG, WebP, etc.)

### Core Interface Concepts
* **Asset Library**: Central gallery storing all imported user assets with instant thumbnail previews.
* **Live Preview Panel**: Real-time asset inspector with playback controls and dimension details before desktop deployment.
* **Overlay Engine**: Transparent, click-through, scalable desktop canvas holding active animated overlays.
* **State Persistence**: Automatic saving and restoration of overlay coordinates, scales, and lock states across application and OS restarts.
* **Inspector Controls**: Granular adjustments for opacity, scale, position coordinates, and lock/unlock toggles.
